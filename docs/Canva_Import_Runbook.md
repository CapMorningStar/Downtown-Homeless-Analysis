# 🎨 Canva 1-Click Import Runbook

Because the `python-pptx` scripts generated `Assignment9_StrategicSynthesis.pptx` using exact 16:9 widescreen dimensions and native shapes, you do **NOT** need to rebuild this presentation by hand in Canva. 

You can instantly import it and apply native Canva aesthetics (like human-made icons, better shadows, and organic layouts) in 10 seconds.

## 🚀 3-Step Import Process

1. **Open Canva**: Go to [canva.com](https://www.canva.com) and log in.
2. **Drag & Drop**: Locate `Assignment9_StrategicSynthesis.pptx` in your local project folder (`/Users/kyawsoelwin/MSI/Downtownhomelessness/`). Drag the file and drop it directly onto the Canva homepage. 
   *(Alternatively, click **Create a design** > **Import file**).*
3. **Open & Edit**: Canva will parse the PPTX. All text boxes, KPI cards, and charts will become **editable Canva elements**.

## 🖌️ Recommended Polish Steps in Canva
Once imported, take 5 minutes to humanize the design:
* **Typography:** Select all slides (Cmd+A) and change the fonts to a modern pairing like **Bricolage Grotesque** (Headers) and **Inter** or **Poppins** (Body).
* **Icons:** Replace any plain text bullets with real Canva icons (e.g., a "Map" icon for the Hotspot slide, a "Chart" icon for the Forecast slide).
* **Charts:** The high-res 300 DPI charts generated by Python will import perfectly as images. You can add a subtle drop-shadow effect to them in Canva to make them pop off the canvas.
